### 🧠 我在做什么

**智能文档处理（IDP）全链路** —— 从数据到模型到产品：

- 🧪 **数据合成**：[SealGenForOCR](https://github.com/yjmm10/SealGenForOCR) ⭐6 · 印章/文档图像生成
- 🔍 **识别与理解**：[Docr](https://github.com/yjmm10/Docr) 模块化 OCR 组件 · [docvlm](https://github.com/yjmm10/docvlm) 文档多模态理解
- 👁 **工程化**：[Visionary](https://github.com/yjmm10/Visionary) OCR 可视化调试

**AI Agent 系统** —— 把工作流变成技能：

- 🤖 [lusca-skill](https://github.com/yjmm10/lusca-skill)：论文检索精读 · PDF 解析 · 科技写作 · 报告博客化
- 🧭 [academic-skill-nav](https://github.com/yjmm10/academic-skill-nav)：学术技能导航
- 📜 [patent-skills](https://github.com/yjmm10/patent-skills)：专利撰写 Agent

**内容自动化** —— 一键多发，解放创作者：

- ✍️ [MediaSync](https://github.com/yjmm10/MediaSync) ⭐3：知乎 / 掘金 / CSDN / 头条 / WordPress 同步
- 🧩 [csdn-anno](https://github.com/yjmm10/csdn-anno)：CSDN 专家标注助手（Chrome / Edge / Firefox）
